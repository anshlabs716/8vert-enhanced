# Development

This page describes how to set up a development environment and work on
8vert-enhanced.

## Requirements

- Python 3.6 or newer
- Tkinter (usually bundled with Python)

## Getting the code

```bash
git clone https://github.com/anshlabs716/8vert-enhanced.git
cd 8vert-enhanced
```

## Build

```bash
# No build step. Run directly:
```

## Run

```bash
python3 8vert-enhanced.py
```

## Test

```bash
python3 -m py_compile 8vert-enhanced.py
```

## Workflow

- Branch from `main` (see [CONTRIBUTING.md](../CONTRIBUTING.md)).
- Keep changes focused and documented.
- Update `CHANGELOG.md` for user-facing changes.
