# Testing

This page describes how 8vert-enhanced is tested and how to run the tests yourself.

## Running the tests

```bash
python3 -m py_compile 8vert-enhanced.py
```

## What is covered

Manual testing of conversions and calculations.

## Adding tests

- Add tests alongside the code they cover.
- Prefer testing behavior over implementation details.
- Keep fixtures free of real personal data, keys, or credentials.

## Current status

Automated test coverage is a work in progress. Contributions that add tests are
welcome.
